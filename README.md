# ATM Machine Simulation in C

A menu-driven ATM simulation developed in C. The program allows users to authenticate with a PIN and perform basic banking operations such as checking balance, depositing money, and withdrawing money.

## Features

- PIN authentication
- Check account balance
- Deposit money
- Withdraw money
- Transaction counter
- Input validation
- Menu-driven interface

## Concepts Used

- Functions
- Conditional statements
- Switch statements
- Loops (`do-while`)
- Function parameters and return values
- User input and output

## Sample Menu

```text
1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit
```
